درس ۷: توابع در Python

در این درس یاد می‌گیریم چگونه بخش‌های قابل استفاده مجدد از برنامه را با تابع بسازیم.

🧠 تابع چیست؟

تابع یک بخش از کد است که برای انجام یک کار مشخص ساخته می‌شود. بعداً می‌توانیم هر زمان که خواستیم آن را اجرا کنیم.

1️⃣ ساخت تابع با def

برای ساخت تابع در Python از کلمه def استفاده می‌کنیم. 

def hello():
    print("Hello!")

hello()

در این مثال ابتدا تابع ساخته شده و سپس با نوشتن نام آن اجرا شده است.

2️⃣ تابع با پارامتر

می‌توانیم اطلاعاتی را به تابع بدهیم. به این اطلاعات پارامتر گفته می‌شود. 

def hello(name):
    print("Hello", name)

hello("Ali")

خروجی:

Hello Ali

3️⃣ چند پارامتر 

def add(a, b):
    print(a + b)

add(5, 3)

خروجی:

8

4️⃣ استفاده از return

با return می‌توانیم یک مقدار را از تابع برگردانیم. 

def add(a, b):
    return a + b

result = add(5, 3)

print(result)

خروجی:

8

🔄 چرا از تابع استفاده کنیم؟

  • کاهش تکرار کد
  • مرتب‌تر شدن برنامه
  • استفاده مجدد از کد
  • ساده‌تر شدن مدیریت پروژه
اگر یک کار را چند بار در برنامه انجام می‌دهی، ساختن یک تابع می‌تواند انتخاب خوبی باشد.

💡 مثال کوچک 

def welcome(name):
    return "خوش آمدی " + name

message = welcome("Ali")

print(message)

درس ۳: انواع داده‌ها در Python

در این درس با چهار نوع داده مهم در Python آشنا می‌شویم.

🧠 نوع داده چیست؟

هر مقداری که در برنامه استفاده می‌کنیم یک نوع داده دارد. نوع داده به Python کمک می‌کند بفهمد با آن مقدار چگونه رفتار کند.

1️⃣ String — متن

📝 String

برای ذخیره متن استفاده می‌شود. معمولاً متن را داخل کوتیشن قرار می‌دهیم. 

name = "Ali"

print(name)

2️⃣ Integer — عدد صحیح

🔢 Integer یا int

برای اعداد صحیح مانند 10، 25 و 100 استفاده می‌شود. 

age = 13

print(age)

3️⃣ Float — عدد اعشاری

🔸 Float

برای اعداد دارای قسمت اعشاری استفاده می‌شود. 

price = 19.5

print(price)

4️⃣ Boolean — درست یا غلط

✅ Boolean یا bool

Boolean فقط دو مقدار اصلی دارد: True و False. 

is_student = True

print(is_student)

🔍 تشخیص نوع داده با type()

با تابع type() می‌توانیم نوع یک مقدار را بررسی کنیم. 

age = 13

print(type(age))

خروجی تقریباً به این شکل خواهد بود: 

<class 'int'>

💡 نکته

به این دو مقدار دقت کن: 
10

"10"
عدد 10 یک عدد صحیح است، اما "10" یک متن است.

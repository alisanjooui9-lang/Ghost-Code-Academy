درس ۱۰: مدیریت خطاها در Python

در این درس یاد می‌گیریم خطاهای برنامه را کنترل کنیم تا برنامه به شکل مناسب‌تری رفتار کند.

❌ خطا چیست؟

گاهی برنامه به دلیل یک مشکل نمی‌تواند کاری را که می‌خواهیم انجام دهد. این مشکل می‌تواند باعث ایجاد یک Exception شود. 

number = int("hello")

در این مثال تبدیل متن به عدد ممکن نیست و Python خطا ایجاد می‌کند.

🛡️ try و except

برای کنترل بعضی خطاها می‌توانیم از try و except استفاده کنیم. 

try:
    number = int("hello")

except:
    print("یک خطا رخ داد")

اگر داخل بخش try خطایی رخ دهد، کد داخل except اجرا می‌شود.

🎯 کنترل یک خطای مشخص

بهتر است تا جای ممکن نوع خطا را مشخص کنیم. 

try:
    number = int("hello")

except ValueError:
    print("مقدار وارد شده عدد نیست")

🔢 مثال تقسیم بر صفر 

try:
    result = 10 / 0

except ZeroDivisionError:
    print("تقسیم بر صفر امکان‌پذیر نیست")

🧹 finally

بخش finally در پایان اجرای ساختار خطا اجرا می‌شود. 

try:
    print("شروع")

except:
    print("خطا")

finally:
    print("پایان")
برای برنامه‌های واقعی بهتر است خطاها را مشخص و قابل فهم مدیریت کنیم، نه اینکه همه خطاها را بدون بررسی با یک except عمومی پنهان کنیم.

💡 مثال کاربردی 

try:

    age = int(input("سن: "))

    print("سن شما:", age)

except ValueError:

    print("لطفاً یک عدد وارد کنید")

اگر کاربر به‌جای عدد یک متن وارد کند، برنامه پیام مناسب نمایش می‌دهد.

📝 تمرین درس

درس ۹: کار با فایل‌ها در Python

در این درس یاد می‌گیریم چگونه فایل‌ها را باز کنیم، اطلاعات داخل آن‌ها را بخوانیم و اطلاعات جدید بنویسیم.

📂 باز کردن فایل

برای کار با فایل‌ها می‌توانیم از تابع open() استفاده کنیم. 

file = open("data.txt", "r")

حرف r یعنی فایل برای خواندن باز شده است.

📖 خواندن فایل 

file = open("data.txt", "r")

content = file.read()

print(content)

file.close()

تابع read() محتوای فایل را می‌خواند.

✍️ نوشتن داخل فایل

برای نوشتن اطلاعات می‌توانیم از حالت w استفاده کنیم. 

file = open("data.txt", "w")

file.write("Hello Python!")

file.close()
حالت w می‌تواند محتوای قبلی فایل را جایگزین کند؛ پس هنگام استفاده از آن باید دقت کنیم.

➕ اضافه کردن اطلاعات

با حالت a می‌توانیم اطلاعات را به انتهای فایل اضافه کنیم. 

file = open("data.txt", "a")

file.write("\nNew line")

file.close()

🔒 روش بهتر با with

استفاده از with باعث می‌شود مدیریت فایل ساده‌تر شود. 

with open("data.txt", "r") as file:

    content = file.read()

    print(content)
با پایان یافتن بلوک with، فایل به شکل مناسب مدیریت می‌شود.

🧠 حالت‌های مهم فایل

  • r → خواندن
  • w → نوشتن
  • a → اضافه کردن

💡 مثال کاربردی 

with open("score.txt", "w") as file:

    file.write("Ali: 100")

این برنامه متن موردنظر را داخل فایل ذخیره می‌کند.

درس ۳: Dataset چیست؟

آشنایی با داده‌های آموزشی و نقش آن‌ها در هوش مصنوعی

📊 Dataset چیست؟

Dataset یا مجموعه‌داده مجموعه‌ای از اطلاعات است که برای تحلیل، آموزش یا آزمایش یک سیستم هوش مصنوعی و یادگیری ماشین استفاده می‌شود.

🤖 چرا Dataset مهم است؟

مدل‌های یادگیری ماشین برای پیدا کردن الگو به داده نیاز دارند. کیفیت، مقدار و مناسب بودن داده‌ها می‌تواند روی عملکرد مدل تأثیر زیادی داشته باشد.

مثال ساده:
عکس‌های گربه و سگ → Dataset → آموزش مدل → تشخیص عکس جدید

🧩 اجزای یک Dataset

📥 داده

اطلاعاتی که برای آموزش یا تحلیل جمع‌آوری شده‌اند.

🏷️ Label

در بعضی Datasetها پاسخ یا دسته درست هر نمونه مشخص است.

🔢 Feature

ویژگی‌هایی از داده که مدل می‌تواند از آن‌ها استفاده کند.

🧪 نمونه

هر ردیف یا مورد موجود در مجموعه‌داده می‌تواند یک نمونه باشد.

📋 یک Dataset ساده

سن ساعت مطالعه قبولی
13 2 بله
14 4 بله
13 1 خیر
15 5 بله

در این مثال، سن و ساعت مطالعه می‌توانند ویژگی‌های ورودی باشند و ستون «قبولی» می‌تواند برچسب باشد.

✂️ تقسیم Dataset

در بسیاری از پروژه‌های یادگیری ماشین، داده‌ها به قسمت‌هایی برای آموزش و ارزیابی مدل تقسیم می‌شوند.

🎓 Training Data

برای آموزش مدل استفاده می‌شود.

🧪 Test Data

برای بررسی عملکرد مدل روی داده‌های دیده‌نشده استفاده می‌شود.

⚠️ کیفیت داده

اگر Dataset دارای اطلاعات اشتباه، ناقص، تکراری یا نامناسب باشد، مدل ممکن است نتیجه خوبی نداشته باشد.

  • داده‌ها باید تا حد امکان مرتبط باشند.
  • خطاهای داده باید بررسی شوند.
  • اطلاعات حساس افراد نباید بدون دلیل مناسب جمع‌آوری یا منتشر شود.
  • داده آموزشی باید تا حد امکان نماینده مسئله واقعی باشد.
خلاصه درس:
Dataset = مجموعه‌ای از داده‌ها برای آموزش، آزمایش یا تحلیل مدل

درس ۴: شرط‌ها در Python

با شرط‌ها می‌توانیم کاری کنیم که برنامه بر اساس یک وضعیت، تصمیم متفاوتی بگیرد.

🧠 شرط چیست؟

فرض کن می‌خواهیم بررسی کنیم آیا سن یک کاربر حداقل ۱۳ سال است یا نه. برای این کار می‌توانیم از if استفاده کنیم. 

age = 13

if age >= 13:
    print("مجاز هستی")

اگر شرط درست باشد، کد داخل آن اجرا می‌شود.

1️⃣ if

ساختار ساده شرط: 

if condition:
    # code

در Python بعد از شرط معمولاً از : استفاده می‌کنیم و کد داخل شرط باید با فاصله مناسب نوشته شود.

2️⃣ else

اگر شرط درست نباشد، می‌توانیم از else استفاده کنیم. 

age = 10

if age >= 13:
    print("مجاز هستی")
else:
    print("مجاز نیستی")

3️⃣ elif

وقتی چند حالت مختلف داریم، می‌توانیم از elif استفاده کنیم. 

score = 80

if score >= 90:
    print("عالی")
elif score >= 60:
    print("قبول")
else:
    print("نیاز به تمرین بیشتر")

⚖️ عملگرهای مقایسه‌ای

  • == برابر بودن
  • != نابرابر بودن
  • > بزرگ‌تر
  • < کوچک‌تر
  • >= بزرگ‌تر یا مساوی
  • <= کوچک‌تر یا مساوی

💡 مثال واقعی 

password = "1234"

if password == "1234":
    print("ورود موفق")
else:
    print("رمز اشتباه است")
یادت باشد = برای مقداردهی استفاده می‌شود، اما == برای مقایسه دو مقدار است.

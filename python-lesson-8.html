درس ۸: Dictionary در Python

در این درس با دیکشنری‌ها و مفهوم Key و Value آشنا می‌شویم.

🗂️ Dictionary چیست؟

Dictionary یا دیکشنری ساختاری برای ذخیره اطلاعات به صورت کلید و مقدار است. 

person = {
    "name": "Ali",
    "age": 13
}

در اینجا name و age کلید هستند و مقادیر آن‌ها به ترتیب Ali و 13 هستند.

🔑 دسترسی با Key 

person = {
    "name": "Ali",
    "age": 13
}

print(person["name"])

خروجی:

Ali

➕ اضافه کردن اطلاعات 

person = {
    "name": "Ali"
}

person["age"] = 13

print(person)

✏️ تغییر مقدار 

person = {
    "name": "Ali",
    "age": 13
}

person["age"] = 14

print(person["age"])

خروجی:

14

❌ حذف اطلاعات

با pop() می‌توانیم یک کلید را حذف کنیم. 

person = {
    "name": "Ali",
    "age": 13
}

person.pop("age")

print(person)

🔄 پیمایش Dictionary

می‌توانیم کلیدها را با حلقه پیمایش کنیم. 

person = {
    "name": "Ali",
    "age": 13
}

for key in person:
    print(key)

💡 مثال کاربردی 

player = {
    "name": "Ali",
    "level": 10,
    "coins": 500
}

print(player["name"])
print(player["coins"])
دیکشنری برای ذخیره اطلاعاتی که هر بخش یک نام مشخص دارد بسیار کاربردی است.

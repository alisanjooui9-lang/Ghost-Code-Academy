درس ۶: لیست‌ها در Python

در این درس یاد می‌گیریم چند مقدار را داخل یک List ذخیره و مدیریت کنیم.

📋 List چیست؟

List یکی از ساختارهای مهم Python است که به ما اجازه می‌دهد چند مقدار را در یک متغیر نگهداری کنیم. 

names = ["Ali", "Reza", "Sara"]

print(names)

در این مثال سه نام داخل یک List قرار گرفته‌اند.

🔢 دسترسی به عناصر List

شماره‌گذاری عناصر List از صفر شروع می‌شود. 

names = ["Ali", "Reza", "Sara"]

print(names[0])
print(names[1])
print(names[2])

خروجی:

Ali
Reza
Sara
اولین عنصر List شماره 0 دارد، نه 1.

➕ اضافه کردن با append()

با append() می‌توانیم یک مقدار جدید به انتهای List اضافه کنیم. 

names = ["Ali", "Reza"]

names.append("Sara")

print(names)

خروجی:

["Ali", "Reza", "Sara"]

❌ حذف کردن با remove()

با remove() می‌توانیم یک مقدار را از List حذف کنیم. 

names = ["Ali", "Reza", "Sara"]

names.remove("Reza")

print(names)

خروجی:

["Ali", "Sara"]

📏 تعداد عناصر با len()

تابع len() تعداد عناصر List را به ما می‌دهد. 

names = ["Ali", "Reza", "Sara"]

print(len(names))

خروجی:

3

🔄 استفاده از List در حلقه

می‌توانیم با حلقه for روی عناصر یک List حرکت کنیم. 

names = ["Ali", "Reza", "Sara"]

for name in names:
    print(name)

خروجی:

Ali
Reza
Sara

💡 نکته مهم

یک List می‌تواند انواع مختلف داده را داشته باشد؛ البته در پروژه‌های واقعی بهتر است ساختار داده‌ها را با هدف برنامه هماهنگ کنیم. 
data = ["Ali", 13, 19.5, True]

📝 تمرین درس

برای اضافه کردن یک مقدار به انتهای List معمولاً از کدام تابع استفاده می‌کنیم؟

درس ۵: حلقه‌ها در Python

با حلقه‌ها می‌توانیم یک بخش از برنامه را چندین بار اجرا کنیم.

🧠 حلقه چیست؟

گاهی لازم است یک دستور را چند بار اجرا کنیم. به‌جای اینکه همان کد را بارها بنویسیم، می‌توانیم از حلقه استفاده کنیم.

حلقه‌ها یکی از مهم‌ترین ابزارهای برنامه‌نویسی هستند.

1️⃣ حلقه for

از for زمانی استفاده می‌کنیم که معمولاً می‌دانیم چه تعداد تکرار لازم داریم یا می‌خواهیم روی یک مجموعه حرکت کنیم. 

for i in range(5):
    print(i)

خروجی:

0
1
2
3
4

🔢 تابع range()

تابع range() برای تولید یک دنباله از اعداد استفاده می‌شود. 

for i in range(1, 6):
    print(i)

خروجی:

1
2
3
4
5
عدد انتهایی در range() شامل نمی‌شود.

2️⃣ حلقه while

حلقه while تا زمانی که یک شرط درست باشد ادامه پیدا می‌کند. 

x = 1

while x <= 5:
    print(x)
    x += 1

خروجی:

1
2
3
4
5

⚠️ حلقه بی‌نهایت

اگر شرط while هیچ‌وقت False نشود، حلقه می‌تواند برای همیشه ادامه پیدا کند. 

x = 1

while x <= 5:
    print(x)
    x += 1
در حلقه‌های while حتماً دقت کن که در نهایت شرط بتواند False شود.

🛑 دستور break

با break می‌توانیم حلقه را متوقف کنیم. 

for i in range(10):

    if i == 5:
        break

    print(i)

در این مثال وقتی i به 5 برسد، حلقه متوقف می‌شود.

⏭️ دستور continue

با continue می‌توانیم اجرای همان دور از حلقه را رد کنیم و به دور بعدی برویم. 

for i in range(5):

    if i == 2:
        continue

    print(i)

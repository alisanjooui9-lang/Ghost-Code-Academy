🐍 Python چیست؟

Python یک زبان برنامه‌نویسی ساده و قدرتمند است که برای ساخت برنامه، وب‌سایت، ابزارهای مختلف، تحلیل داده و پروژه‌های هوش مصنوعی استفاده می‌شود.

یکی از ویژگی‌های مهم Python، خوانایی نسبتاً ساده کدهای آن است.

🚀 اولین برنامه

برای نمایش یک متن در Python می‌توانیم از دستور print() استفاده کنیم. 

print("Hello World!")

با اجرای این برنامه، عبارت زیر نمایش داده می‌شود: 

Hello World!

💡 یک مثال فارسی 

print("سلام دنیا!")

🧠 نکته مهم

در Python، حروف بزرگ و کوچک متفاوت هستند. مثلاً: 
print()
با: 
Print()
یکی نیستند.
